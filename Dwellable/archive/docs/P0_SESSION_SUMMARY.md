1. **P0 Feature Set Locked In:** Gallery, Tags/Headlines, Notifications, Soak, Headlines. No additions without architectural review.

6. **Success Definition:** WAR (Weekly Active Reflections) = primary metric. 40-50% weekly return by week 8 = P0 success.
