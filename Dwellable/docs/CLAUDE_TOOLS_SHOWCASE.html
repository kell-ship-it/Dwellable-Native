The Meta Pattern

Every tool here follows the same principle: Claude builds the interactive shell, you fill in the decisions. The HTML becomes a shared workspace — structured enough that Claude understands what you're reviewing, flexible enough that you can annotate, export, and iterate.

The most powerful tools below (marked Shareable) are not Dwellable-specific. They're reusable patterns any founder, PM, or engineer can adapt to work better with Claude.

Collab Loop
How the Review → Respond Loop Works

The Collab Review Doc introduces a new pattern for working with Claude on strategy and design.

STEP 01
Open the doc in Safari
The strategy doc is pre-loaded as readable HTML. Read through it normally.
STEP 02
Highlight + Comment
Select any text. A "Add Comment" button appears. Type your question, challenge, or note. It saves automatically.
STEP 03
Export Comments
Hit Export. It downloads a .txt with every comment, the text it's anchored to, and its section. Share this with Claude.
STEP 04
Claude responds
Claude reads the export, writes responses, and updates the HTML file directly — adding responses into the agentResponses object.
STEP 05
Refresh to see replies
Refresh the browser. Agent responses appear inline in purple below each of your comments. Loop repeats.
