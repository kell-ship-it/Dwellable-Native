Happy Paths (5)

Path 1: Discover an Emerging Theme CORE
Scenario: User captures 3-4 moments over 2 weeks mentioning doubt/questioning. App detects theme "Wondering" and invites reflection.
1. User Captures Moment #4 → "I'm questioning whether God is listening"
2. Theme Detection (Background) → LLM finds pattern: doubt/questioning in moments 1, 3, 4
3. Theme Emerges → System marks "Wondering" (abstracted from user's language)
4. Gentle In-App Indication → Optional subtle notification "A pattern is emerging"
5. User Sees Themes Dashboard → User opens app, sees themes in "Themes" dashboard
6. Tap Theme → See 3 moments + how user talked about it + prompt: "You've sat with this 3 times. What are you noticing?"
Path 2: Explore Themes in Reflection CORE
Scenario: User reading journal entry about doubt sees linked themes showing how this moment connects to broader patterns.
1. In Dwelling Place → User reading journal entry about doubt
2. See Linked Themes → Bottom shows "This moment relates to: Wondering (3 moments)"
3. Tap to Explore → User taps theme link
4. View Theme Context → See all 3 moments + timeline of when theme emerged
5. Reflection Prompt → "You've visited this struggle across these moments. What's shifted?"
6. Guided Reflection → Optional: respond with prayer or prompt sequence (Pillar 3 integration)
7. Return → User can return to original moment or continue exploring
Path 3: Weekly Theme Summary CORE
Scenario: User receives optional weekly summary of emerging themes (pull-based, not push).
1. User Opens App → Sees "Weekly themes" card (optional feature)
2. View Summary → "This week you reflected on: Hope (2 moments), Relational Joy (3 moments), Guidance (1 moment)"
3. Tap Theme → Can dive into any theme to see moment context
4. Reflection Prompt → "What story is emerging across these themes?"
5. Pray or Journal → User can respond, or dismiss and return later
Path 4: Filter Search by Theme CORE
Scenario: User in Search mode filters moments by detected themes (integrates with Pillar 6).
1. In Search → User browsing moments from past month
2. Apply Theme Filter → User taps "Filter by theme" and sees detected themes
3. Select Theme → User chooses "Wondering"
4. See Filtered Results → Only moments tagged with "Wondering" appear
5. Explore Context → User sees how theme evolved across moments
6. Return to Search → User can remove filter or add more filters
Path 5: Monthly Formation Review CORE
Scenario: User reviews spiritual journey over a month and sees the arc of themes that emerged.
1. From Dashboard → User taps "Monthly Review" or "Formation View"
2. See Month's Themes → Visual or text summary: "In April, your journey included..."
• Joy & Gratitude (5 moments)
• Uncertainty (4 moments)
• Breakthrough (2 moments)
3. View Timeline → Themes appear chronologically so user sees arc
4. Reflection Questions → "How did Joy & Gratitude emerge after Uncertainty?"
5. Spiritual Discernment → User sees their own story, makes their own meaning

Locked Decisions (8) ✓

1. Theme Detection Trigger
Decision: Automatic detection when theme appears 3+ times (or configurable threshold)
2. Rich Context Required
Decision: Themes use conversation history + user's language, not just keyword frequency
3. Invitational Framing
Decision: All prompts are questions, never directives ("What patterns do you notice?" not "Here's what this means")
4. No Interpretation
Decision: Themes surface observed patterns; user interprets meaning. App is witness, not interpreter.
5. User Language
Decision: Theme names use user's own words/phrases when possible (abstracted but authentic)
6. Theme Linking
Decision: Themes link moments to journals, enabling cross-moment reflection
7. Timeline View
Decision: Show when themes emerged and evolved over time
8. Privacy by Default
Decision: Theme detection is on-device first (optional cloud sync for cross-device)
