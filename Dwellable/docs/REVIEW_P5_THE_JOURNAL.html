Pillar 5: The Journal

Review & lock the design skeleton. Approve or note changes, then click Done.

Happy Paths

Path 1View Journal Detail — User opens synthesized journal from Dwelling Place. Sees title, body, date captured, moods (2-3 tags), attached photos, prayer reference, original transcript link (read-only), last-edited timestamp.
Path 2Select/Customize Moods — User taps mood section, selects 2-3 moods from predefined palette (Reflective, Hopeful, Conflicted, Grieving, Joyful, etc.). Can deselect and update. Moods persist and affect Formation Intelligence.
Path 3Add/Manage Journal Photos — User adds photos to journal (from capture time or after synthesis). Can reorder, add captions per photo, remove photos. Photos encrypted with journal.
Path 4Add Custom Headlines/Summary — User adds headline/summary distinct from auto-generated title. Useful for quick scanning in Dwelling Place list. Editable, optional. Example: "Three breakthroughs in one morning."
Path 5Edit Journal Title & Body (Post-Synthesis) — User modifies auto-generated title (4-6 words) and body paragraphs (2-3 paragraphs). Marked as edited with timestamp. Recover original version (backlog).
Path 6Format Journal Text — User applies basic formatting: bold, italics, lists, paragraphs. Synthesized body starts plain text; user adds structure. Formatting persists in encrypted content.
Path 7Delete & Recover Journal — User soft-deletes journal (flags with deleted: true, deletedAt, recovery deadline). Hidden from Dwelling Place and search. Recoverable from Trash within 30 days.

Open Items

Headlines vs. Titles — Separate Fields?

Headlines are a separate metadata field (Path 4 as-is)
Fold headlines into title editing (combine Path 4 + Path 5)

Text Formatting (Path 6) — Phase 2 or Defer?

Include in Phase 2 — rich text editor
Defer to Post MVP — plain text + line breaks for MVP (recommended)

Photo Management — When Can Photos Be Added?

At capture time only (Pillar 1)
At capture time OR after journal is created (recommended)

Mood Selection — Mandatory or Optional?

Mandatory — user must select 2-3 moods before saving journal
Optional — user can leave moods blank (recommended)

Transcript Access — Show or Hide Original Conversation?

Show original transcript as read-only link in journal detail
Hide transcript — accessible only from Moments list (recommended)

Continue Chat with Prompts Post-Journal Creation?

Yes — user can continue conversation with prompts after journal is created
No — conversation ends at journal creation (recommended for MVP)
