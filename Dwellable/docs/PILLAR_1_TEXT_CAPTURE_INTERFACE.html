Flow Summary

Text Message Capture Flow:
  1. Initiation: User lands on capture screen with toggle (voice/text icon) + prompts carousel
  2. Tap text icon: Shifts to message-style interface with system prompt at top
  3. User responds: Types in input field; message bubbles appear naturally
  4. Can continue: System can offer follow-up prompts (optional, swipeable)
  5. Submit: User taps send or "Done capturing" → triggers save + LLM headline generation
  6. Completion screen: Shows moment + headline, offers "Pray on This" or alternative actions

Key Differences from Current TypeFlowView

Current (Build 107): Full-screen text input, form-like, minimal context

Phase 2 Beta Pillar 1: Chat bubble interface, conversational, prompts provide gentle guidance, feels like dialogue not form submission

Integration with Other Pillars

Pillar 0 (Onboarding): First text capture during onboarding uses this interface
Pillar 2 (Security): Captured text encrypted before sync
Pillar 3 (Soaking): Completion screen CTA "Pray on This Moment" routes to prayer/prompts flow
Pillar 4 (Editing): Auto-generated headline editable post-capture
