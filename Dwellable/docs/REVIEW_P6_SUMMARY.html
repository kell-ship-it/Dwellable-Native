Pillar 6: Search & Discovery

Complete summary of all decisions, paths, and items for final verification before locking.

Happy Paths (6)

Paths 2 & 6 deferred to Post MVP. Paths 1, 3, 4, 5 confirmed for MVP.
Path 1: Full-Text Search CONFIRMED
User types keyword or phrase to search moments & journals. Results appear with context snippets, sorted newest first.
• Search field with placeholder "Search moments & journals..."
• Real-time results as user types (debounced)
• Result preview shows snippet + date + moods
• Tap result to open full detail view
• Searches across moment transcripts AND journal bodies
Path 2: Filter by Date Range DEFERRED
User filters search results by date (past week, past month, custom range). Deferred to Post MVP.
• Preset options: Past week, Past month, Past 3 months
• Custom date picker for specific ranges
• Can combine with search + mood filters
• Status: PHASE 3+ (complexity, lower priority)
Path 3: Filter by Mood/Theme CONFIRMED
User filters moments by mood (Reflective, Conflicted, Exhausted, Hopeful, Loved, Prayerful) or detected themes. Core MVP feature.
• Mood palette showing all available moods
• Multi-select (checkboxes)
• Results narrow to matching moods
• Can combine mood + full-text search + date (when Post MVP added)
• Integration point: Pillar 7 themes will extend this filter
Path 4: Browse by Date (Chronological Gallery) CONFIRMED
User casually browses moments in chronological order (newest first) without searching. MVP view: Calendar + infinite scroll journal reflections.
• Gallery/Timeline view mode (alternate from search)
• Reverse chronological order (newest first)
• Date headers ("May 2026", "April 2026", etc.)
• Infinite scroll through moments
• Tap moment to open detail view
• MVP LOCK: Calendar + Infinite Scroll View
Path 5: Saved/Pinned Moments CONFIRMED
User marks moments as favorites (heart/star icon) to return to them easily. Pinned status persists across sessions.
• Heart/star icon in moment detail header
• Tap to pin/unpin (toggles)
• Visual feedback (heart fills in when pinned)
• Can filter by "Pinned" or view "Favorites" view
• Pinned status persists (stored in DB)
• Pinned items included in search results with special indicator
Path 6: Search by Sense of Lord DEFERRED
User filters moments by "Sense of Lord" data (spiritual insights). Deferred to Post MVP pending Pillar 7 integration.
• Filter option: "Sense of Lord" (if data exists)
• Shows moments with populated senseOfLord field
• Can combine with other filters
• Status: PHASE 3+ (depends on Pillar 7 completion & theme integration)

Locked Decisions (8) ✓

These 8 decisions are locked and ready for implementation. Confirm each.
1. Full-Text Search Scope LOCKED
Full-text search is enabled across both moment transcripts AND journal bodies (both searchable).
2. Encryption-Aware Search LOCKED
Search index is encrypted or uses privacy-preserving methods. No plaintext index on server.
3. Real-Time Results LOCKED
Search results appear as user types (debounced to reduce server load).
4. Result Context & Preview LOCKED
Search results display snippet of matching text + metadata (date, moods) for context.
5. Filter Combination (AND Logic) LOCKED
Support AND logic: mood + date + search all apply together. When both search and mood filter are active, results must match BOTH.
6. Sort Options LOCKED
Default sort = newest first; allow toggle to oldest first.
7. Exclude Soft-Deleted Items LOCKED
Soft-deleted moments/journals are excluded from search results (filter by deleted: false).
8. Search Index Encryption LOCKED
Search index is encrypted using AES-256-GCM (consistent with Pillar 2 encryption strategy).
