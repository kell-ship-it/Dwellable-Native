Executive Summary

**Phase 1 Problem:** 100% adoption of voice-first moment capture, but **0% return rate**. Users captured moments but never revisited them—defeating the spiritual formation purpose.

**Phase 2 Solution:** P0 (Return focus) solves the dwelling gap through a coordinated feature set: Gallery (visual retrieval), Tags/Headlines (user-generated metadata), Notifications (gentle invitations), and Soak Mode (contemplative presence). Each feature honors the Five Strategic Foundations while maintaining Dwellable's core promise: *keeper of sacred moments, not interpreter.*

**Success Criteria:** Weekly Active Reflections (WAR) = **40-50% of users return weekly by week 8**. This is the primary go/no-go metric for P0 success.

**Phase Sequencing:** P0 (Return), P1 (Dwelling), P2 (Formation), P3 (Deepening). Each phase validates solo functionality before adding collaborative features.

---

Five Strategic Foundations (Phase 2 Guardrails)

1. **Keeper of Sacred Moments, Not Interpreter**

Dwellable holds moments, makes return effortless, but never tells users what their moments mean.

2. **Socratic Reflection, Not Interpretation**

Features invite pattern-finding and user-generated insight; never prescriptive spiritual direction.

3. **User Agency, Hermeneutical Alignment, Scripture Authority**

Users control their reflection practice. All features optional. No algorithm. No curated external content.

4. **End-State Principle: Formed Christian Through Accumulated Witness**

Over time, accumulation of user's own moments—not external teaching—shapes spiritual formation.

5. **Personal Spiritual Moments, Not Generic Notes**

Every feature focuses exclusively on user's own moments. No comparison, ranking, or external content.

P0 Feature Set (May–August 2026, 90 days)

Gallery View

**What:** Tile-based visual catalog of moments with date, headline, preview. Tap to open full detail.

**Why:** Visual gallery drives 3x+ re-engagement (Stoic App, Day One research). Shifts moment retrieval from forgetting to browsing.

**Foundation Alignment:** ✅ All five — keeper (visual presentation), Socratic (invites pattern-finding), user agency (no algorithmic curation), end-state (accumulated visual witness), personal (user's moments only).

Tags & Headlines

**What:** User-written headlines (retrieval cues) + optional auto-suggested tags (5 max per moment). Examples: "God's peace in uncertainty," tags: Presence, Peace, Waiting.

**Why:** Metadata enables pattern recognition (user discovers: "60% of my moments involve solitude") and recall (+40-60% retrieval improvement). User-generated only—preserves voice.

**Foundation Alignment:** ✅ All five — keeper (descriptive, not interpretive), Socratic (patterns prompt questions), user agency (optional, user controls), end-state (patterns reveal spiritual arc), personal (user's language, user's taxonomy).

Notifications (2x Weekly)

**What:** Gentle reflection invitations (Sunday 6 PM, Thursday 7 AM). Examples: "How are you sitting with your moments?" "What patterns do you notice?" User-controllable frequency (1x, 2x, or mute).

**Why:** Gentle notifications drive 2x re-engagement; 2x weekly is optimal (avoids fatigue). Invitational copy ("How...?") vs. prescriptive ("Reflect on...") keeps Socratic frame.

**Foundation Alignment:** ✅ All five — keeper (open-ended invitations), Socratic (question-based copy), user agency (fully optional, customizable), end-state (contemplation of spiritual growth), personal (references user's moments only).

Soak Mode

**What:** Optional 5/10/15-minute contemplative mode with ambient soundscape (piano, rain, forest, etc.) + moment text visible. User chooses duration and music type.

**Why:** Ambient soundscape + contemplative threshold (7+ minutes) shifts session duration from 30 seconds → 5-15 minutes, supporting pre-verbal presence and spiritual formation.

**Foundation Alignment:** ✅ All five — keeper (silence + presence, not instruction), Socratic (contemplation precedes questions), user agency (entirely optional, 35-40% adoption), end-state (supports faith deepening), personal (user alone with their moment).

Headlines (User-Generated Retrieval Cues)

**What:** Optional user-written headline (8-word default if not customized). Appears in gallery tile + detail view header.

**Why:** Headlines serve as retrieval triggers ("Why did that matter?") and cumulative pattern markers ("faith arc: doubt → trust → peace"). User-generated only—no AI interpretation.

**Foundation Alignment:** ✅ All five — keeper (retrieval cues, user's language), Socratic (recall-based reflection), user agency (optional, user writes), end-state (language patterns show spiritual journey), personal (user's voice throughout).

Success Metrics & Go/No-Go Criteria

Primary Metric: Weekly Active Reflections (WAR)

**Definition:** Percentage of DAU (Daily Active Users) who return to review/dwell on at least one moment in a given week.

| Timeline | Metric | Success Threshold | Risk Level |

|----------|--------|-------------------|-----------|

| Week 1–2 | WAR adoption | 15–25% return | 🟡 Monitor—users discovering features |

| Week 3–4 | WAR engagement | 25–35% return | 🟡 Monitor—habit formation period |

| Week 5–8 | WAR stabilization | **40–50% return** | 🟢 P0 Success—sustainable dwelling |

| Week 9+ | WAR retention | 50%+ sustained | 🟢 Ready for P1 transition |

Go/No-Go Decision Point (Week 8):

  • ✅ **GO to P1** if WAR ≥ 40% sustained for 2 consecutive weeks
  • ❌ **NO-GO** if WAR < 35% by week 8 → Pause P1, iterate P0 features

    • Secondary Metrics (Diagnostic)

    | Metric | Target | Rationale |

    |--------|--------|-----------|

    | Gallery adoption | 85%+ voluntary | Visual retrieval should be primary entry point |

    | Notification open rate | 25–35% | Gentle frequency; not all users need reminders |

    | Soak adoption | 35–40% | Optional feature; contemplative diversity |

    | Tags adoption | 40–50% | Metadata adds friction; reasonable adoption |

    | Average soak duration | 7+ minutes | Contemplative threshold for spiritual benefit |

    Foundation Alignment Metrics (Qualitative)

    | Foundation | Success Question | Target |

    |-----------|-----------------|--------|

    | **Keeper** | "Dwellable respects my interpretation" (agree/strongly agree) | 85%+ |

    | **Socratic** | "I discover insights myself in Dwellable" | 60%+ of active users |

    | **User Agency** | Voluntary adoption rates (no gamification/streaks) | Gallery 85%, Tags 50%, Notifications 60% |

    | **End-State** | "I see my faith deepening through dwelling" | 65%+ by week 8 |

    | **Personal** | "Dwellable feels personal to my faith journey" | 80%+ |

    Phase Gates & Feature Progression

    P0 → P1 Gate (Dwelling Focus)

    P0 is complete when:

  • ✅ WAR ≥ 40% sustained for 2 weeks (primary metric)
  • ✅ Foundation alignment ≥ 80% on qualitative survey
  • ✅ Soak adoption ≥ 30% (indicates contemplative receptivity)
  • ✅ Zero critical bugs blocking dwellingwork

    • P1 Features Unlock (Only after P0 gate passes):

  • Socratic Reflection prompts (guided questions tied to moments)
  • Themes & Patterns (AI-surfaced topic clusters from user's moments)
  • Scripture Integration (optional Bible anchoring for moments)
  • Seasonal Assessment (faith journey tracking over 3-month cycles)

    • **Why Sequential:** P1 adds *guided* reflection. This only works if P0 proves users voluntarily return *unguided*. If P0 fails (WAR < 40%), P1's prompts may feel like nagging. Phase gates protect strategic integrity.

    Risk Mitigation

    Top 5 Risks & Mitigations

    | Risk | Impact | Mitigation |

    |------|--------|-----------|

    | **User Discovery Failure** — Gallery/Soak features exist but users don't find them | WAR drops 30-40% | Progressive feature onboarding on first return; in-app explainers for Gallery + Soak |

    | **Notification Fatigue** — 2x weekly feels intrusive for some users | Opt-out rate > 30% | Default OFF; customize frequency (1x, 2x, pause 1–4 weeks); sunset copy variants monthly |

    | **Soak Mode Technical Issues** — Audio crashes, sync problems | User frustration; uninstall | Extensive pre-release QA on audio stack; offline audio library (no streaming) |

    | **Scope Creep** — Adding social/AI features during P0 | Brand drift; theological misalignment | Strictly enforce scope boundaries: P0 = solo dwelling only. Social deferred to P2. |

    | **Retention Cliff** — Return rate peaks at week 4, then drops | WAR < 40% by week 8 | Reserve mid-P0 design review (week 4) to iterate copy, onboarding, notification timing based on early data |

    Scope Boundaries (What P0 Does NOT Include)

    ❌ Social features (sharing, ranking, comparison)

    ❌ AI interpretation or auto-generated headlines

    ❌ Forced practices (daily streaks, gamification)

    ❌ External content (devotionals, verses, quotes)

    ❌ Recommendation engines ("users like you...")

    ❌ Prescriptive categories ("God's Faithfulness")

    ❌ Spiritual direction (guidance, advice)

    These features are explicitly deferred to P1/P2/P3 phases and will only be considered if P0 succeeds.
