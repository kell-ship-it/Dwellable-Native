P0: Onboarding Flows — Model 1 vs Model 2

Initial Decision Screen (Both Models)

Every new user starts here. Returning users go directly to Sign-In.

┌─────────────────────────┐ │ Dwellable │ │ │ │ [ Sign Up ] │ │ │ │ Already have account? │ │ [ Sign In ] │ └─────────────────────────┘
Flow:
  • Sign In → Sign-In Screen (email/password, Google, Apple)
  • Sign Up → Carousel → Model 1 or Model 2

Models Side-by-Side

MODEL 1: Embedded & Progressive

Questions feel conversational, one step at a time.

Carousel (4 cards) [Problem] [Value] [Education] [Trust] ↓ ┌──────────────────────┐ │ What should we │ │ call you? │ │ │ │ [ Name ] │ │ │ │ [Next] │ └──────────────────────┘ ↓ ┌──────────────────────┐ │ What brings you to │ │ Dwellable? │ │ │ │ [ Interest/reason ] │ │ │ │ [Next] │ └──────────────────────┘ ↓ ┌──────────────────────┐ │ Secure your moments │ │ with God │ │ │ │ Email: [ _ ] │ │ Password: [ _ ] │ │ │ │ [Create Account & │ │ Capture] │ └──────────────────────┘ ↓ Capture Screen ↓ ✓ Moment saved
Key: No separate "Create Account" screen. Progressive flow feels like an extension of capturing.

MODEL 2: Dedicated Account Screen

All account details on one screen, then capture.

Carousel (4 cards) [Problem] [Value] [Education] [Trust] ↓ ┌──────────────────────┐ │ CREATE ACCOUNT │ │ │ │ Name: [ _ ] │ │ Email: [ _ ] │ │ Password: [ _ ] │ │ │ │ What brings you? │ │ [ _ ] │ │ │ │ [Create Account] │ └──────────────────────┘ ↓ Capture Screen ↓ ✓ Moment saved
Key: Clear visual break with "CREATE ACCOUNT" header. All fields collected in one place.

Sign-In Screen (Both Models)

Existing users or those choosing to sign in see this:

┌──────────────────────┐ │ SIGN IN │ │ │ │ Email: [ _ ] │ │ Password: [ _ ] │ │ │ │ [Sign in with Email] │ │ │ │ ─── OR ─── │ │ │ │ [Sign in with Google]│ │ [Sign in with Apple] │ │ │ │ Don't have account? │ │ [Sign Up] │ └──────────────────────┘ ↓ [Home / Menu Bar]

Side-by-Side Comparison

Aspect Model 1 (Progressive) Model 2 (Dedicated Screen)
Visual breaks Minimal (feels conversational) One clear break ("CREATE ACCOUNT")
Form fields per screen 1–2 fields at a time All fields at once (name, email, password, interest)
Cognitive load Lower (progressive) Higher (all at once)
Tone Conversational, intimate Transactional, clear
Time to capture Slightly longer (more screens) Slightly faster (one form)
Drop-off risk Spread across multiple screens Concentrated on one screen
