Pillar 5: Editing

Review & lock the design skeleton. Approve or note changes, then click Done.

Happy Paths

Path 1 Edit Transcript (Pre-Synthesis) — User corrects transcription errors on the Review screen before journal is generated.
Path 2 Edit Journal Title & Body (Post-Synthesis) — User opens journal detail view, taps Edit, modifies title/body. Saved with edited: true flag.
Path 3 Delete Moment (Soft Delete) — Deletes moment AND its journal. 30-day recovery window. Disappears from list and search results.
Path 4 Delete Journal Only (Preserve Moment) — Deletes only the synthesized journal. Original moment stays. User can re-journal later.
Path 5 Recover Deleted Item (Future) — Trash view shows items deleted within 30 days. User can restore.
