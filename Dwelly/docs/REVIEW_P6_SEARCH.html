Happy Paths

Path 1Full-Text Search — User types keyword/phrase, real-time results across moments & journals with snippet previews.
Path 2Filter by Date Range — Preset (past week/month/3 months) or custom date picker. Combinable with search.
Path 3Filter by Mood/Theme — Select from mood palette (Reflective, Hopeful, Conflicted, etc.), multi-select, combinable.
Path 4Browse Chronologically — Gallery/Timeline view with date headers. Scroll to browse, tap to open detail.
Path 5Saved/Pinned Moments — Heart/star icon pins a moment. Filterable by "Pinned." Persists across sessions.
Path 6Filter by Sense of Lord — Shows only moments where the "Sense of Lord" field is populated. Combinable.
